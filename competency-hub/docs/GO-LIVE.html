ESG Competency Hub – going live

The steps from a finished TEST system to everyone using the Hub, in order. Do them once Releases 1 to 6 are installed (the steps in each release's HOW-TO) and every check there has passed. Updated 24 October 2026.

Each step changes the live site. Nothing here can be undone in the app, apart from the clean-up, which keeps everything in the recycle bin for 93 days.

1. A week before

  1. Permission probe again. Run the P2 probe with the test colleague (the HOW-TO step with Rich). Every row should pass, including the refused notice after Can post notices is switched off.
  2. Power Automate use. In the Power Platform admin centre, open Analytics → Power Automate (or each flow's Analytics) and note the runs and actions per day over a normal week. Your account's daily allowance (6,000 requests) is shared with the 1-to-1 flows. If the total is above about 4,500 a day, reduce the queue monitor's hours under Administration → Settings → Queue monitor hours (for example 07:00–18:00, hourly outside), and tell me.
  3. The staff list. Have the 28 people ready as one line each: email, role, area keys (for example firstname.lastname@…, Technician, GRS RP). Engineers get Can run meetings in their areas; technicians don't, unless you tick it later.

2. On the day, before anyone is told

  1. Health. Administration: the first card should say processing, reminders, emails and meetings are all working, and Changes needing attention should be empty.
  2. Remove the test data. Administration → Remove test data. Everything marked as a test record is listed. Under Made before marking, tick the early TEST actions, notices and meetings from before Release 2. Type REMOVE TEST DATA and confirm. Within a few minutes it reports how many were removed, and test marking is switched off. (Turn ESG Competency Hub | 8 Clean-up on first, and off again afterwards.)
  3. Add the staff. Administration → People → Add people → Or paste a list: paste the 28 lines and send them. Each line is email, role, area keys, Known as; take the Known as name from known-as.txt (for example firstname.lastname@…, Technician, GRS RP, Rachel). Or set them all afterwards with the Known as box in Setup. Each person shows Done and verified once their access has been read back. Any line that can't be found in Microsoft 365 is reported; correct it and send that one again.
  4. Check two people. Open one technician and one engineer in People: their areas, meeting rights and notice posting are as intended.
  5. Book the first real meetings, or let each area's engineers do it on the first day.

3. Tell everyone

Send one email from yourself, with the staff guide (STAFF-GUIDE.html, or printed as a PDF) attached. A suggested text:

Subject: The ESG Competency Hub is live

From today, our actions, notices, improvements and degradations, and monthly meetings are in the ESG Competency Hub. Please use this link, and bookmark it: [the Hub page address ending ?env=WebView]

The Hub shows your own actions first. You'll get an email when an action is given to you, and a reminder before it is due. The one-page guide attached shows the main things you can do.

If anything looks wrong or could be better, use the Feedback button at the bottom of any page.

4. The first fortnight

  • Look at Administration each morning: health, changes needing attention, and new feedback.
  • Alert emails come to the administrators if anything needs them; Power Automate also emails you if a flow fails repeatedly.
  • Send me anything odd, with a screenshot and the time it happened.

If something goes wrong

What you seeWhat to do
A banner saying changes can't be processedIn Power Automate, check that every ESG Competency Hub flow is On, and look at the run history of the one named in the banner.
Invitations not arrivingCheck the Outlook connection; if it can't be fixed quickly, set Outlook invitations to No. People use Add to my calendar.
PDF minutes not appearingCheck the OneDrive connection; if it can't be fixed, set PDF minutes to No. Finalised minutes have Print.
Your account's password changedIn Power Automate, open each connection of the solution and sign in again.
