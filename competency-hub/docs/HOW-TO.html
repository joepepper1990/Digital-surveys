ESG Competency Hub – installing release 1.2

25 October 2026. Release 1.2 is the version you approved in the preview. Install it in the order below: Setup first, then the solution, then the app. Allow about 30 minutes, plus a short session with Rich.

App 1.2.2 – meetings without waiting, on a steady screen. If you have already installed release 1.2, only Step 3 is needed (the app files):
  • Start meeting opens the live screen at once. The agenda is fixed in the background, and outcomes you record meanwhile stay with their items.
  • Finalise shows the minutes at once, marked as being saved. The PDF follows a few minutes later.
  • The meeting screen stays still while it catches up: it no longer flashes or rebuilds when things are saved, and stays on the item you're on, even if you go through the agenda quickly.
  • A meeting booked a moment ago can be started straight away. What you record is sent as soon as the booking is saved. Raising or closing actions from it waits for the booking, usually under a minute.

What changes for people using the Hub

  • Changes show at once. When you raise, move, finish or change something, the screen shows it straight away, marked ✓ Sent. When it is recorded, the mark turns into a green ✓✓ Saved, which fades after a few seconds. You can carry on meanwhile; buttons don't disappear.
  • One line under the top bar says Everything is up to date, or what is still saving. It replaces the yellow strips, so the page no longer jumps.
  • If a change can't be saved, a card says why, with Try again and Dismiss, and the screen goes back to how the record really is. If someone else changed it first, nothing was changed. If the system had a fault, an administrator has been told. Trying again is safe either way: it can never make the change twice.
  • Home: Mark as done on each to-do card (then Reopen if it was a slip). There are no summaries beside the headings, and a week with nothing in it is one line.
  • Raise an action from the top bar no longer chooses an area for you (the Flask problem). Step 2 asks Which area is it for?, and the summary names the area in large type.
  • Notices and issues fit the screen: the notice on the left, comments on the right. Less-used buttons are under More for this notice or More for this issue.
  • Actions: More for this action holds Edit this action, Give it to someone else, Change its status and Close this action.
  • Meetings:
    • Items are labelled Action, Issue, Notice or Other business, and each offers only its own buttons:
      • actions: Close this action and Raise a further action;
      • issues and notices: Turn into an action.
    • + Add an item sits with the agenda, and the new item opens straight away.
    • Finalised minutes have Open the PDF, Download PDF and Amend these minutes.
    • The minutes and the PDF use people's Hub names. They list Actions closed at this meeting, and the actions raised at the meeting with their owner and due date.
  • Overview of all areas: the numbers are coloured badges; click any one to see exactly those actions. Area pages: each tab has its own buttons at the top.
  • Administration gains How long changes take: for the last 7 days, how long each kind of change took to be picked up and saved.
